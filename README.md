A program that sums up the world's news of Thursday 19 November 2026 in one image. It writes the image to /output/entry.png: a dated infographic with six labelled story cards covering the day's biggest stories — the first-ever Trump–Xi–Putin trilateral in Shenzhen, the World Court's genocide ruling against Myanmar over the Rohingya, Anthropic's soaring Nasdaq debut, the GTA VI global rollout, the third Crimean Bridge strike in four days, and Voyager 1's one-light-day milestone. The image is drawn with exact text (no generated-text artefacts) and is 1024×1024 pixels.

## Run it

```sh
python3 main.py
```

Verified locally: two runs into different directories produced byte-identical copies of entry.png (matching SHA-256 hashes).
